# 多人场景与外观分配

多人是最容易出错的地方，核心原则是**外观按出场顺序写，每人一组，不交叉**。

## 人数标记

`1girl` `1boy` `2girls` `2boys` `1girl, 1boy` `3girls` `group`

## 外观分配

错误写法（外观全部堆在一起，模型会串）：
```
2girls, long hair, short hair, black hair, brown hair, blue eyes, green eyes
```

正确写法（按顺序，角色一的特征连续写完再写角色二）：
```
2girls, 1girl with long black hair and brown eyes, 1girl with short blonde hair and blue eyes
```

## 规则

1. 先写人数标记，再依次写每个角色的外观
2. 每个角色的发型、发色、瞳色、肤色**只出现一次**
3. 两个角色的瞳色默认错开（如 brown / blue），避免模型混淆
4. 服装在 `cl` 字段按同样顺序分配
5. 动作在 `po` 字段写清谁对谁做什么，如 `hugging from behind, arms wrapped around waist`

## 站位提示

双人构图可以补一个站位说明，例如 `standing side by side`、`facing each other`、`one behind the other`，能显著降低串味概率。
