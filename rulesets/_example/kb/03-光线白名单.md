# 光线白名单

放在 `x` 字段。**只能使用本表里的具名光，禁止自造光影形容词。**

## 方向类

`backlighting` 逆光 / `sidelighting` 侧光 / `front lighting` 顺光 / `top lighting` 顶光 / `underlighting` 底光

## 光源类

`sunlight` 阳光 / `moonlight` 月光 / `candlelight` 烛光 / `streetlight` 路灯 / `fluorescent light` 日光灯 / `window light` 窗户光 / `fireplace` 壁炉光

## 时段类

`daytime` 白天 / `sunset` 日落 / `golden hour` 黄金时刻 / `night` 夜晚 / `dawn` 黎明 / `dusk` 黄昏

## 影暗类

`shadow` 阴影 / `silhouette` 剪影 / `chiaroscuro` 明暗对照 / `lens flare` 镜头光斑

## 禁止词（自造光影词）

`warm light` `cool light` `soft light` `soft lighting` `cinematic lighting` `moody lighting` `dramatic lighting` `beautiful lighting` `rim light` `top light`

这些词模型看到后会自由发挥，导致每次出图光线不一致。想要"暖的感觉"就用 `sunset` 或 `candlelight` 这类具名光。
