# 镜头与构图

放在 `x` 字段，决定画面怎么裁。

## 景别（从大到小）

`extreme wide shot` 大远景 → `wide shot` 远景 → `full body` 全身 → `cowboy shot` 膝上 → `upper body` 半身 → `portrait` 胸上 → `close-up` 特写 → `extreme close-up` 大特写

## 机位

`from above` / `from below` / `from side` / `from behind` / `dutch angle` 斜角 / `straight-on` 正面平视

## 视线

`looking at viewer` 看镜头 / `looking away` 看向别处 / `looking back` 回头 / `eye contact` 对视

## 构图原则

1. 单人像优先 `upper body` 或 `portrait`，主体占画面高度三分之二左右
2. 要展示服装全貌时用 `full body`
3. 多人场景先定景别再定机位，否则容易主体过小
4. 景别和机位**各选一个**，不要叠加三四个
