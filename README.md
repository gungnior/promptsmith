# PromptSmith

**用本地大模型把中文自然语转写成结构化提示词的工作台。**

程序本身不含任何规则——规则集全部从外部目录加载，换技能不改代码、不重打包。

---

## 它解决什么问题

在聊天窗口里让模型写提示词，有三个绕不开的坑：

1. **模型不触发技能** —— 小模型经常不调技能加载，只拿到默认系统提示，于是按对齐规则拒答
2. **取多少块不可控** —— 模型自己决定读几个文件，可能一路读到上下文塞满
3. **不知道它读了什么** —— 出图不满意时无法回溯

PromptSmith 的做法：**不让模型自己取文件**。

```
中文描述 → 程序本地读规则集 → 关键词+别名+词表打分取前 N 块 → 算 token 超预算自动降块
        → 调本地模型一次 → 结构化提示词
```

好处：**零权限弹窗**（模型不碰文件系统）、**取几块你说了算**、**物理上撞不到上下文上限**。

## 功能

| 类别 | 功能 |
|---|---|
| 生成链路 | 规则集加载 → 四路检索 → 预算闸 → 生成 → 校验 → 无历史重跑 1 次 |
| 人工干预 | 拖拽选块、锁定、清空、双击编辑 md、超预算标红并建议删哪块 |
| 检索 | IDF 加权、n-gram 中文分词、规则集私有别名、中英词表、可选向量兜底 |
| 词典 | 增删改 + 未命中记录 + **联网抓官方中文名/热度/相关 tag**（只发 tag 名，不发你的描述） |
| 自动学习 | 你手动选的块会自动记成别名；白名单清洗，不进上下文 |
| 界面 | 深浅色、三栏可拖、正面/负面/全部三 Tab 分开复制、快捷键、草稿自动存 |
| 批量 | 一行一条串行跑，可停止、单条复制、单条收藏 |
| 收藏夹 | 磁盘持久化，换浏览器不丢 |
| 入口三档 | 全量 / 精简 / 核心，界面一键切 |

详细设计与实测数据见 [SPEC.md](SPEC.md)。

## 快速开始

### 环境要求

- Windows / Linux / macOS
- Python 3.9+（**无需任何第三方包**，纯标准库）
- 一个本地模型服务，OpenAI 兼容端点（llama.cpp / Ollama / LM Studio / vLLM 均可）

### 运行

```bat
启动PromptSmith.bat
```

浏览器打开 <http://127.0.0.1:8765/> 。端口被占用会自动顺延到 8776，以界面左上角为准。

或者手动：

```bash
python src/server.py 8765
```

### 接你的模型

设置面板（右上角 ⚙）里改三项：`base_url`、`model`、`n_ctx`。

比如 llama.cpp 默认是 `http://127.0.0.1:8081/v1`，Ollama 是 `http://127.0.0.1:11434/v1`。

### 换规则集

把文件夹放进 `rulesets\`（或在设置里添加任意目录），重启即出现在顶栏下拉框。

三种形态都能加载：

| 形态 | 目录 |
|---|---|
| 完整包 | `profile.json` + `system.md` + `kb/*.md` |
| 现成技能 | `SKILL.md` + `references/` |
| 纯块目录 | 一堆 `*.md` |

`rulesets\_example\` 是一个中性示例，装好即可跑通全流程。

## 关于「模型拒答」

程序会把「角色 + 输出格式契约」写死在 system 里，**每次请求都带着**。

实测：同一个模型、同一句请求，只改 system——

| system | 结果 |
|---|---|
| `You are a helpful assistant.` | 拒绝 |
| 角色 + 固定字段格式 | 3/3 正常输出 |

所以不需要去找"破限模型"。格式框架本身就覆盖拒绝。

---

## 关于向量兜底

内置 Ollama bge-m3 向量检索能力，**默认关闭**。

实测在规则型语料上区分度不足（cos 标准差仅 0.048，开与不开排序完全一致），因为这类语料块间语义高度同质。对素材型 / 图注型语料可能有效，自行在设置里开关。

## 目录结构

```
PromptSmith\
├── src\                程序本体（不含任何技能知识）
├── web\ui.html         界面（单文件，零前端依赖）
├── data\config.json    模型设置 + 规则集搜索路径
├── rulesets\           规则集（_example 为中性示例）
├── vectors\            向量缓存（可选）
├── cases\              收藏夹
├── backups\            块编辑自动备份
└── SPEC.md             完整设计文档与实测数据
```

## 安全与隐私

- **只监听 `127.0.0.1`**，不弹防火墙
- 联网词典**只发送 tag 名**，绝不发送你的描述或生成结果
- 收藏夹、别名学习、未命中记录全部存在本地
- 代码零第三方依赖，可自行审计
